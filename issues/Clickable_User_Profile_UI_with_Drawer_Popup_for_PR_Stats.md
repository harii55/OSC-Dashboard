## Clickable User Profile UI with Popup/New Page for PR Stats

### Description
The user profile should open a popup or a complete new page for displaying PR stats, whichever fits best. The goal is to enhance usability by providing clear access to relevant information about the user’s contributions.

### Request for Feedback
I would like to ask the maintainers to share their opinions on which approach is preferred: a popup or a new page. Your insights are valuable to help us make the best decision for this feature.
